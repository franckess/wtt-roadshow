# WTT US Roadshow 2026 shot list

A day-by-day shot list for René and Vivienne's What The Tech (AU) US Roadshow, 29 October to 16 November 2026. It's a single static page, `index.html`, served by GitHub Pages.

Ticks are saved in each phone's browser and don't sync between devices.

Each day has a "Look it up" section: Google search links for the public places that day names (the `LOOK` table in `index.html`), and a box for checking a name, title or term on the spot. Links open a new tab without sending the page's address. The wedding, friends, hotels and pending visits get no links. Why it exists, and how it feeds the editing pipeline's research step, is recorded as decisions D55 and D56 in the `wtt-video-agent` repository.

Booking times are as the source itinerary reported them and haven't been checked against tickets.
